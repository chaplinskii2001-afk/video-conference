# Параллелизация Whisper и PyAnnote

## Описание изменений

Система была переведена на параллельную обработку моделей Whisper и PyAnnote. Вместо последовательного выполнения (сначала транскрипция, потом диаризация), обе модели теперь загружаются и работают одновременно.

## Как это работает

### Старый процесс (последовательный):
1. Загрузка аудио
2. Загрузка Whisper → Транскрипция → Выгрузка Whisper
3. Загрузка PyAnnote → Диаризация → Выгрузка PyAnnote
4. Объединение результатов
5. Загрузка Qwen → Суммаризация → Выгрузка Qwen

**Время**: Т = T_whisper + T_pyannote + T_qwen

### Новый процесс (параллельный):
1. Загрузка аудио
2. Загрузка Whisper и PyAnnote (параллельно)
3. Транскрипция и Диаризация (параллельно через asyncio.gather)
4. Выгрузка Whisper и PyAnnote
5. Объединение результатов
6. Загрузка Qwen → Суммаризация → Выгрузка Qwen

**Время**: Т = max(T_whisper, T_pyannote) + T_qwen ≈ T_qwen + max(T_whisper, T_pyannote)/2

## Техническая реализация

### Параллелизм
- Используется `asyncio.gather()` для одновременного выполнения задач
- Обе модели загружаются до запуска обработки
- GPU может одновременно обрабатывать Whisper и PyAnnote (если позволяет память)

### Управление памятью
- Параметр `skip_unload=True` предотвращает выгрузку текущей модели при загрузке новой
- Метод `unload_whisper_and_diarization()` удаляет обе модели одновременно
- `current_loaded_model` не обновляется при параллельной загрузке (остается None)

### Обработка ошибок
- Если одна из моделей не загружается, выбрасывается исключение
- Обе модели гарантированно выгружаются в блоке `finally`
- Использован `return_exceptions=False` в `asyncio.gather()` для пробрасывания исключений

## Вмешательство для обратной совместимости

Методы `transcribe_audio()` и `diarize_audio()` остаются и могут использоваться отдельно для обратной совместимости. Параметр `skip_unload` по умолчанию `False`, поэтому они работают как раньше (с выгрузкой модели).

## Улучшение производительности

Ожидаемое улучшение зависит от времени работы каждой модели:
- Если T_whisper ≈ T_pyannote, то общее время сокращается примерно в 2 раза для этого этапа
- Если одна модель работает значительно быстрее, экономия времени будет меньше
- На современных GPU обе модели могут работать параллельно без значительного снижения производительности
