# Заметки по рефакторингу проекта

## 📝 Что было сделано

Проект был полностью переработан для достижения трех целей:

### 1️⃣ Масштабируемость для мощных GPU

**Было**: 
- Жестко заданные параметры квантования
- Нет адаптации под разное железо

**Стало**:
- `config.py` - новый модуль с автоопределением GPU
- 4 профиля производительности:
  - **Базовый** (4-6 GB): Whisper 8bit, Qwen 4bit → RTX 3050 (текущий)
  - **Средний** (8-12 GB): Whisper float16, Qwen 8bit → RTX 3060/3070
  - **Мощный** (16-24 GB): Whisper float16, Qwen float16 → RTX 4080/A4000
  - **Профессиональный** (24+ GB): Whisper float32, Qwen float16 → A5000/A6000
- При смене GPU система автоматически подстраивается

**Как это работает**:
```python
# Приложение само определяет GPU и выбирает оптимальные параметры
gpu_config = GPUConfig.get_config_for_current_gpu()
# Возвращает: профиль, квантование, размер батча, лимиты
```

### 2️⃣ Улучшенный код, логирование и мониторинг GPU

**Было**:
- Один большой файл 795 строк
- Базовое логирование
- Нет отслеживания памяти GPU

**Стало**:
- **config.py** (145 строк) - конфигурация
- **gpu_manager.py** (236 строк) - управление GPU памятью
- **model_manager.py** (346 строк) - управление AI моделями
- **video_processor.py** (800 строк) - главная логика

**Новые возможности**:

1. **Детальное логирование GPU**:
```

🧹 Очистка GPU (standard): освобождено 1.23 GB, свободно 2.55 GB
```

2. **Снимки памяти** на каждом этапе:
```python
self.gpu_manager.take_snapshot("before_transcription")
# Автоматически логирует состояние памяти
```

3. **Сводка по завершении**:
```

============================================================

before_diarization  : 0.78 GB использовано (13.0%)
```

## 🚀 Как это использовать

### Разработчику

1. **Запуск**:
```bash
docker-compose up -d
```

2. **Логи с GPU мониторингом**:
```bash
docker-compose logs -f | grep GPU
```

3. **Проверка конфигурации**:
```bash
curl http://localhost:8000/model-status
# Покажет текущий профиль GPU и параметры квантования
```

### При обновлении GPU

**Ничего не нужно менять!** 

Просто замените видеокарту и перезапустите:
```bash
docker-compose restart
```

Приложение автоматически:
- Определит новую GPU
- Выберет оптимальный профиль
- Применит нужное квантование
- Скорректирует лимиты обработки

### Для тонкой настройки

Если нужна ручная настройка - измените `config.py`:

```python
# Добавить свой профиль
"custom": {
    "name": "Мой профиль",
    "min_vram_gb": 10,
    "max_vram_gb": 16,
    "whisper_quantization": "float16",
    "qwen_quantization": "8bit",
    "batch_size": 3,
    ...
}
```

## 🔧 Техническая архитектура

```
main.py                           ← FastAPI сервер
  ↓
video_processor.py                ← Главная логика
  ↓
  ├─→ config.py                   ← Конфигурация GPU
```
