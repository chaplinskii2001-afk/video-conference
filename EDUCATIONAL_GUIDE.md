# 🎓 Руководство по использованию для учебной/исследовательской среды

## 📋 Обзор

Этот документ содержит специальные инструкции для использования системы обработки видео-конференций в учебной и исследовательской среде. Система адаптирована для образовательных целей с дополнительными функциями для исследований.

## 🚀 Новые возможности для исследований

### 1. Автоматическое определение возможностей системы

```bash
# Получите детальную информацию о GPU и рекомендации
curl http://localhost:8000/performance-recommendations
```

**Что показывает:**
- Информация о GPU (если доступен)
- Рекомендуемые настройки производительности
- Советы по оптимизации

### 2. Анализ системной производительности

```bash
# Анализ пригодности для исследований
curl http://localhost:8000/system-capacity
```

**Возможные оценки:**
- **Excellent**: 24+ GB GPU, 8+ CPU ядер, 32+ GB RAM
- **Good**: 12+ GB GPU, 6+ CPU ядер, 16+ GB RAM  
- **Acceptable**: 8+ GB GPU, 4+ CPU ядра, 8+ GB RAM
- **Limited**: Менее минимальных требований

### 3. Настройки для учебной среды

```bash
# Информация о настройках для образования
curl http://localhost:8000/educational-setup
```

**Особенности:**
- Увеличенные лимиты размера файлов (до 1GB)
- Длительное время обработки (до 4 часов)
- Подробное логирование для анализа
- Сохранение промежуточных результатов

## 🔧 Оптимизация производительности

### Для разных типов GPU

#### Мощные GPU (24+ GB памяти)
- **RTX 4090, A100 и аналоги**
- Рекомендуется: модели без квантования
- Пакетная обработка файлов
- Экспериментальные функции

#### Средние GPU (12-16 GB памяти)  
- **RTX 3080, 4070 Ti и аналоги**
- Рекомендуется: 8-bit квантование Whisper
- Подходит для большинства исследований

#### Бюджетные GPU (8-12 GB памяти)
- **RTX 3060, 3070 и аналоги**
- Рекомендуется: квантование всех моделей
- Последовательная обработка
- Контроль использования памяти

#### Слабые GPU или CPU (<8 GB памяти)
- Только для демонстрации и обучения
- Максимальная оптимизация памяти
- Короткие файлы (до 30 минут)

## 📊 Рекомендации по размеру файлов

| Тип GPU | Максимальный размер файла | Тип обработки | Время обработки |
|---------|---------------------------|---------------|-----------------|
| 24+ GB  | До 1GB                   | Параллельная  | 10-30 мин      |
| 12-16 GB| До 500MB                 | Последовательная | 15-45 мин   |
| 8-12 GB | До 200MB                 | Последовательная | 20-60 мин   |
| <8 GB   | До 100MB                 | Последовательная | 30+ мин     |

### Сценарий 1: Анализ качества транскрипции

```python
# Пример запроса
import requests

# Загружаем файл
with open('conference_recording.wav', 'rb') as f:
    response = requests.post('http://localhost:8000/process', 
                           files={'file': f},
                           data={'summary_type': 'standard'})
    
task_id = response.json()['task_id']

# Проверяем прогресс
while True:
    progress = requests.get(f'http://localhost:8000/progress/{task_id}')
    data = progress.json()
    
    if data['status'] == 'completed':
        break
    elif data['status'] == 'error':
        print(f"Ошибка: {data['error']}")
        break
    
    print(f"Прогресс: {data['percent']}%")
    time.sleep(5)
```

## 🐛 Обработка ошибок в учебной среде

### Подробные сообщения об ошибках

Система предоставляет расширенную информацию об ошибках:

```json
{
    "error_type": "TRANSCRIPTION_ERROR",
    "message": "Ошибка транскрипции аудио sample.wav",
    "details": {
        "audio_path": "sample.wav",
        "reason": "Whisper model failed to load"
    },
    "learning_tip": "Проверьте качество аудио, наличие речи и правильность формата.",
    "debugging_suggestions": [
        "Проверьте качество аудио (должна быть четкая речь)",
        "Убедитесь, что аудио содержит речь, а не музыку",
        "Проверьте, что Whisper модель загружена"
    ],
    "learning_resources": {
        "concepts_to_study": [
            "Автоматическое распознавание речи (ASR)",
            "Whisper архитектура"
        ],
        "documentation_links": [
            "https://github.com/openai/whisper"
        ]
    }
}
```

### Образовательные советы для разных ошибок

| Тип ошибки | Образовательные советы |
|------------|------------------------|
| MODEL_LOADING_ERROR | Изучите архитектуру Transformer, квантование |
| AUDIO_PROCESSING_ERROR | Изучите форматы аудио, ffmpeg |
| TRANSCRIPTION_ERROR | Изучите ASR технологии, качество аудио |
| MEMORY_MANAGEMENT_ERROR | Изучите управление памятью в PyTorch |
