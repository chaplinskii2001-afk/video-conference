# FAQ по оптимизациям

## Общие вопросы

### Q: Почему параллельная обработка не дала ускорения?
**A:** Две модели на одном GPU не могут работать полностью параллельно, так как GPU выполняет операции последовательно. Вместо этого мы оптимизировали каждую модель отдельно и получили 35-50% ускорения.

Подробности: см. `PARALLEL_PROCESSING_EXPLAINED.md`

### Q: Насколько быстрее стала обработка?
**A:** 
- Диаризация: быстрее на 50-70%
- Транскрипция: быстрее на 20-30%
- Общая скорость: быстрее на 35-50%

### Q: Потеряется ли качество?
**A:** Минимальное влияние:
- Float16: разница в точности < 1%
- min_duration_off/on: убирает очень короткие реплики (< 0.5с), что обычно улучшает результат
- BetterTransformer: нет влияния на качество

### Q: Работают ли оптимизации на всех GPU?
**A:** Да! Параметры автоматически подстраиваются под ваш GPU профиль:
- Low (4-6 GB): diarization_batch_size=16
- Medium (8-12 GB): diarization_batch_size=32
- High (16-24 GB): diarization_batch_size=64
- Ultra (24+ GB): diarization_batch_size=128

## Технические вопросы

### Q: Что если BetterTransformer недоступен?
**A:** Оптимизация безопасно пропускается с предупреждением в логах. Whisper будет работать с обычной скоростью.

### Q: Можно ли отключить оптимизации?
**A:** Да, но зачем? Если всё же нужно:

**Отключить float16 для PyAnnote:**
```python
# В model_manager.py закомментируйте строки с .half()
```

**Отключить BetterTransformer для Whisper:**
```python
# В model_manager.py закомментируйте блок try-except с to_bettertransformer()
```

**Изменить параметры диаризации:**
```python
# В video_processor.py измените min_duration_off и min_duration_on на 0.0
```

### Q: Как изменить batch_size для диаризации?
**A:** В файле `config.py` измените параметр `diarization_batch_size` для вашего профиля:

```python
"medium": {
    # ...
    "diarization_batch_size": 64,  # увеличьте для быстрой обработки
    # ...
}
```

**Внимание:** Слишком большой batch_size может привести к OOM (Out of Memory).

### Q: Можно ли ускорить еще больше?
**A:** Да! Дополнительные возможности:

1. **Использовать более лёгкую модель**
   ```python
   # В config.py измените:
   DIARIZATION_MODEL_ID = "pyannote/speaker-diarization-3.0"  # вместо 3.1
   ```

2. **Уменьшить разрешение аудио** (потеря качества ~5-10%)
   ```python
   # В video_processor.py измените sample_rate на 8000 вместо 16000
   ```

3. **Увеличить min_duration** (меньше сегментов, быстрее обработка)
   ```python
   min_duration_off=1.0,  # вместо 0.5
   min_duration_on=1.0,   # вместо 0.5
   ```

4. **Использовать torch.compile()** (требует PyTorch 2.0+)
   ```python
   # В model_manager.py после загрузки модели:
   model = torch.compile(model)
   ```

## Проблемы и решения

### Q: Вижу ошибку "Не удалось включить float16 для PyAnnote"
**A:** Это предупреждение, не ошибка. Модель будет работать в float32. Возможные причины:
- Модель уже в float16
- CPU режим (float16 недоступен на CPU)

### Q: Вижу "BetterTransformer недоступен для Whisper"
**A:** Нужно установить библиотеку optimum:
```bash
pip install optimum
```
Или просто игнорируйте - Whisper будет работать с обычной скоростью.

### Q: GPU память переполняется (OOM)
**A:** Уменьшите batch_size:

**Для Whisper:**
```python
# В config.py уменьшите batch_size:
"batch_size": 1,  # вместо 2
```

**Для диаризации:**
```python
# В config.py уменьшите diarization_batch_size:
"diarization_batch_size": 16,  # вместо 32
```

### Q: Обработка всё равно медленная
**A:** Проверьте:

1. **GPU используется?**
   ```bash
   nvidia-smi
   ```
   Должна быть загрузка GPU во время обработки.

2. **Оптимизации применены?**
   ```bash
   docker-compose logs app | grep -E "BetterTransformer|float16|batch_size"
   ```
   Должны быть сообщения об успешной оптимизации.

3. **Какой GPU профиль?**
   Проверьте в логах при старте:
   ```
   GPU профиль: Средний (8-12 GB VRAM)
   ```

## Мониторинг

### Q: Как посмотреть время выполнения каждой модели?
**A:** В логах ищите строки:
```bash
docker-compose logs -f app | grep -E "WHISPER|PYANNOTE"
```

Вы увидите:
```
🔄 [WHISPER] Начало транскрипции аудио...
✅ [WHISPER] Транскрипция завершена: 245 сегментов за 45.23с

🔄 [PYANNOTE] Начало диаризации аудио...
✅ [PYANNOTE] Диаризация завершена: 189 сегментов за 52.11с
```

### Q: Как проверить использование GPU?
**A:** В реальном времени:
```bash
watch -n 1 nvidia-smi
```
