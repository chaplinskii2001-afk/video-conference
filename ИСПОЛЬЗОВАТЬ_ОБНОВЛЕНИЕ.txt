⚡ САМЫЙ БЫСТРЫЙ СПОСОБ (для нетерпеливых):

1. Откройте терминал

2. Выполните команду (замените <имя_контейнера> на реальное имя):

   docker cp static/* <имя_контейнера>:/app/static/

   Или если не знаете имя, сначала выполните:
   docker ps

3. Обновите страницу в браузере:
   Нажмите: Ctrl+F5 (если Windows/Linux)
   или      Cmd+Shift+R (если Mac)

4. ГОТОВО! 🎉

ШАГ 1: УБЕДИТЕСЬ ЧТО ВЫ НА ПРАВИЛЬНОЙ ВЕТКЕ
─────────────────────────────────────────────

Откройте терминал и выполните:

   git branch

Должно показать:
   * feat/ui-polish-status-display-meeting-logger
     master
     ...

Если звёздочка (*) не рядом с нужной веткой, переключитесь:

   git checkout feat/ui-polish-status-display-meeting-logger


ШАГ 2: СКОПИРУЙТЕ ФАЙЛЫ В КОНТЕЙНЕР
──────────────────────────────────────

Сначала посмотрите какие контейнеры запущены:

   docker ps

Вы должны увидеть что-то типа:
   CONTAINER ID   IMAGE          STATUS      NAMES
   abc123def456   meeting-logger Running     meeting-logger-1

Скопируйте имя контейнера (например: meeting-logger-1)

Теперь скопируйте файлы:

   docker cp static/index.html meeting-logger-1:/app/static/
   docker cp static/style.css meeting-logger-1:/app/static/
   docker cp static/script.js meeting-logger-1:/app/static/

(замените meeting-logger-1 на ваше имя контейнера)


ШАГ 3: ОБНОВИТЕ БРАУЗЕР
────────────────────────

В браузере где открыто приложение:

   Windows/Linux: Нажмите Ctrl+F5
   Mac:          Нажмите Cmd+Shift+R

Это очищает кэш браузера и загружает новую версию файлов.


ШАГ 4: ПРОВЕРЬТЕ ЧТО ВСЁ РАБОТАЕТ
──────────────────────────────────

Откройте приложение (обычно http://localhost:5000)

Загрузите какой-нибудь файл (видео/аудио)

Нажмите "Начать обработку"

На экране обработки должно быть:
   - Большой текст в центре "Идет обработка" + название этапа
   - Прогресс-бар под ним
   - Процент напротив прогресс-бара

❌ НЕ должно быть:
   - Логов внизу
   - 4 маленьких карточек (Download, Transcription, etc.)
   - Раздела "Журнал обработки"

Если это вы видите - значит всё получилось! 🎉

ПРОБЛЕМА: В браузере всё ещё старый интерфейс
──────────────────────────────────────────────

Решение 1 - очистка кэша браузера:
   Windows/Linux: Ctrl+Shift+Delete
   Mac:          Cmd+Shift+Delete
   
   Выберите "Удалить кэшированные изображения и файлы"
   Нажмите "Очистить данные"

Решение 2 - открыть в приватном окне:
   Ctrl+Shift+P (Windows) или Cmd+Shift+P (Mac)
   Откройте http://localhost:5000 в новом приватном окне


ПРОБЛЕМА: Браузер показывает ошибку "Не удалось загрузить скрипт"
──────────────────────────────────────────────────────────────────

Это значит файлы не скопировались в контейнер.

Проверьте что скопировалось:

   docker exec meeting-logger-1 ls -la /app/static/

Должны быть все 3 файла:
   -rw-r--r-- index.html
   -rw-r--r-- style.css
   -rw-r--r-- script.js

Если их нет - скопируйте снова (см. ШАГ 2)


ПРОБЛЕМА: Контейнер не запускается / упал
──────────────────────────────────────────

Выполните:

   docker-compose down
   docker-compose up -d

Посмотрите логи:

   docker-compose logs -f

Если видите ошибки - покажите их тем кто знает Docker 😊


ПРОБЛЕМА: Я в docker-compose.yml использую volume
──────────────────────────────────────────────────

Если у вас есть строка типа:

   volumes:
     - ./static:/app/static

То контейнер автоматически подхватит файлы из вашей папки ./static

В этом случае:
1. Просто скопируйте обновленные файлы в вашу локальную папку ./static
2. Обновите браузер (Ctrl+F5)
3. Готово!
