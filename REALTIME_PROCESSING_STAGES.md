# Система реального времени отображения этапов обработки файла

## Обзор изменений

Реализована система **реального времени отображения этапов обработки** файла для пользователя с понятными и интуитивными названиями.

Проблема, которая была решена:
- ❌ **До**: Пользователь не понимал на каком этапе находится обработка
- ❌ **До**: Технические названия этапов (transcription, diarization) не понятны конечным пользователям
- ✅ **После**: Пользователь видит понятные названия этапов в реальном времени (Транскрипция речи, Определение спикеров)
- ✅ **После**: Каждый этап сопровождается описанием и иконкой для визуального отображения

## Архитектура решения

### 1. Backend: Справочник этапов (`processing/stages.py`)

Новый модуль содержит полную информацию о каждом этапе обработки:

```python
{
    "display_name": "Транскрипция речи",    # Видимое пользователю
    "description": "Распознавание речи (Whisper)",  # Подробное описание
    "icon": "🎤",                           # Визуальная иконка
    "order": 6                              # Порядковый номер
}
```

### 2. Backend: Обновления в Task Manager (`task_manager.py`)

- Каждая задача теперь хранит `current_stage_display` - полную информацию о текущем этапе
- При обновлении прогресса автоматически вычисляется информация о этапе

### 3. Backend: Обновления в API (`main.py`)

Endpoint `/progress/{task_id}` теперь возвращает:
```json
{
    "task_id": "...",
    "status": "processing",
    "percent": 45,
    "current_stage": "transcription",
    "current_stage_display": {
        "display_name": "Транскрипция речи",
        "description": "Распознавание речи (Whisper)",
        "icon": "🎤",
        "order": 6
    }
}
```

### 4. Frontend: Улучшенное отображение этапа

Новый дизайн `stage-display`:

```html
<div class="stage-display">
    <div class="stage-icon" id="stage-icon">🎤</div>
    <div class="stage-content">
        <div class="stage-label">Идет обработка</div>
        <div class="stage-name">Транскрипция речи</div>
        <div class="stage-description">Распознавание речи (Whisper)</div>
    </div>
</div>
```

**Особенности дизайна:**
- Большая иконка с анимацией пульса (48px)
- Название этапа 26px, жирный цвет основной палитры
- Описание этапа серого цвета для контекста
- Анимация пульса иконки создает ощущение "живости"
- Адаптивный дизайн для мобильных устройств

### 5. Frontend: JavaScript обновления (`static/script.js`)

Функция `updateProgressDisplay()` теперь:
- Получает информацию о этапе с сервера
- Обновляет иконку, название и описание в реальном времени
- Включает fallback для совместимости со старыми ответами сервера

## Использование

### Для пользователя
Процесс автоматический и не требует специальных действий. При загрузке файла пользователь видит:
1. Понятное название текущего этапа (например "Транскрипция речи")
2. Описание того, что происходит ("Распознавание речи (Whisper)")
3. Визуальную иконку этапа (🎤)
4. Прогресс-бар с процентами

### Для разработчика
При добавлении новых этапов обработки:

1. Добавить новый этап в `processing/stages.py`:
```python
"my_stage": {
    "order": 10,
    "display_name": "Мой новый этап",
    "description": "Описание для пользователя",
    "icon": "🎯"
}
```

2. Использовать в коде:
```python
self._update_progress(50, "my_stage", "Сообщение логирования...")
```

## Технические детали

### Производительность
- Дополнительные 2-3 вычисления на обновление прогресса (поиск в словаре)
- Negligible impact на производительность
- Данные отправляются только при запросе на `/progress/{task_id}`

### Совместимость
- Полная обратная совместимость с старыми API ответами
- Fallback функция `updateCurrentStageFallback()` при отсутствии `current_stage_display`

### Локализация
- Все названия этапов на русском языке
- Легко добавить поддержку других языков через отдельный справочник

## Результат

Пользователь теперь имеет **четкое понимание** о том:
- ✅ На каком этапе находится обработка
- ✅ Что происходит прямо сейчас
- ✅ Какой инструмент используется (Whisper, PyAnnote, Qwen)
- ✅ Приблизительный прогресс обработки

Это значительно улучшает пользовательский опыт и снижает чувство неопределенности при обработке больших файлов.
