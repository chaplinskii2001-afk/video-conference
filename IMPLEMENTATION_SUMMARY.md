## 🔑 Ключевые компоненты

### 1. ModelManager.load_whisper(skip_unload=True)
Загружает Whisper без выгрузки текущей модели, позволяя загрузить обе модели одновременно.

### 2. ModelManager.load_diarization(skip_unload=True)
Загружает PyAnnote без выгрузки текущей модели.

### 3. VideoProcessor.process_transcription_and_diarization_parallel()
Главный метод параллельной обработки:
1. Загружает обе модели
2. Запускает обе задачи через `asyncio.gather()`
3. Ждет завершения обеих
4. Выгружает обе модели

### 4. asyncio.gather()
Позволяет одновременно выполнять два асинхронных процесса:
- Whisper транскрибирует аудио
- PyAnnote диаризирует аудио

## 🛡️ Безопасность

✅ **Гарантированная выгрузка моделей:**
- Даже при ошибках обе модели выгружаются (finally блок)
- Двойная подстраховка: `unload_whisper_and_diarization()` + `unload_all_models()`

✅ **Обработка ошибок:**
- Если загрузка Whisper не удалась, PyAnnote не загружается
- Если одна из задач завершилась ошибкой, другая все равно выполнится
- Исключение правильно пробрасывается через `asyncio.gather()`
