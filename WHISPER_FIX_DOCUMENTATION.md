# Исправление проблемы с Whisper моделью

## Проблема

После обновления кода с оптимизацией моделей система продолжала пытаться загрузить старую модель `bond005/whisper-podlodka-turbo` вместо новой `Systran/faster-whisper-large-v3`, что приводило к ошибкам:

```
❌ Ошибка загрузки Whisper (faster-whisper): Unable to open file 'model.bin' in model '/app/models/whisper/models--bond005--whisper-podlodka-turbo/snapshots/86e9d7bc08cea8d35555a5c55bb9037aa36ad1f4'
```

## Корневые причины

1. **Кэширование старой модели**: В кэше HuggingFace остались файлы старой модели
2. **Недостаточная очистка кэша**: Предыдущая логика очистки была слишком мягкой
3. **Отсутствие диагностики**: Не было достаточно логирования для отслеживания источника проблемы

## Решения

### 1. Улучшенное логирование диагностики

Добавлено подробное логирование в критических точках:

```python
self.logger.info(f"🔍 ДИАГНОСТИКА МОДЕЛИ WHISPER:")
self.logger.info(f"   gpu_config.whisper_model_id: {self.gpu_config.get('whisper_model_id')}")
self.logger.info(f"   model_config.whisper_id: {self.config['model_config']['whisper_id']}")
self.logger.info(f"   final whisper_id: {whisper_id}")
```

### 2. Агрессивная очистка кэша

Заменена мягкая очистка на агрессивную:

- Удаляются ВСЕ папки, которые не соответствуют новой модели
- Очищается глобальный кэш HuggingFace
- Удаляются lock-файлы и временные данные
- При ошибках выполняется ПОЛНАЯ очистка с пересозданием директории

### 3. Принудительная загрузка в Dockerfile

Обновлен Dockerfile для принудительной загрузки правильной модели при сборке:

```dockerfile
# 1. Whisper (faster-whisper / CTranslate2) - ПРИНУДИТЕЛЬНО С ПРАВИЛЬНОЙ МОДЕЛЬЮ
RUN echo "🔧 ПРИНУДИТЕЛЬНАЯ ЗАГРУЗКА МОДЕЛИ Systran/faster-whisper-large-v3" && \
    rm -rf /app/models/whisper/* && \
    python3 -c "from faster_whisper import WhisperModel; \
    print('Loading Systran/faster-whisper-large-v3...'); \
    model = WhisperModel('Systran/faster-whisper-large-v3', device='cpu', compute_type='int8', download_root='/app/models/whisper'); \
    print('✅ faster-whisper model downloaded successfully'); \
    import os; print('Contents:', os.listdir('/app/models/whisper'))"
```

### 4. Улучшенная повторная попытка загрузки

При ошибках загрузки модель теперь:
- Выполняет полную очистку директории
- Пересоздает директорию
- Явно указывает правильную модель для повторной загрузки

## Измененные файлы

1. **`processing/model_manager.py`**:
   - Добавлена диагностика модели при инициализации
   - Реализована агрессивная очистка кэша
   - Улучшена повторная попытка загрузки
   - Очистка глобального HuggingFace кэша

2. **`docker/Dockerfile`**:
   - Принудительная загрузка правильной модели при сборке
   - Очистка директории перед загрузкой
   - Проверка успешности загрузки

## Как это работает

1. **При запуске приложения**: Диагностика показывает, какая модель должна использоваться
2. **При загрузке модели**: Агрессивная очистка удаляет старые модели
3. **При ошибках**: Выполняется полная очистка и повторная загрузка правильной модели
4. **При сборке Docker**: Автоматически загружается и кэшируется правильная модель
