# Тестирование исправления суммаризации

## Процесс тестирования

### 1. Тест на коротком файле (5-10 минут)

```bash
# Загрузить короткое видео (5-10 минут)
# Проверить результат в summary файле
# Ожидаемый результат: Полное краткое содержание без обрезания
```

**Проверочные критерии:**
- [ ] Краткое содержание имеет все секции: "Общая тематика", "Основные темы", "Ключевые тезисы", "Итоги"
- [ ] Текст не обрезан в середине слова или предложения
- [ ] Все основные моменты из видео захвачены

### 2. Тест на длинном файле (30+ минут)

```bash
# Загрузить длинное видео (30+ минут)
# Проверить результат в summary файле
# Ожидаемый результат: Полное краткое содержание без обрезания
```

**Проверочные критерии:**
- [ ] Краткое содержание имеет все секции
- [ ] Текст корректно объединен из нескольких частей
- [ ] Нет дублирования информации

### 3. Проверка логов

```bash
# Проверить логи обработки
docker-compose logs -f app | grep -i "summarization\|tokens"
```

**Ожидаемые логи:**
```
Начало суммаризации (standard): XXXX символов
Текст разбит на X частей
Суммаризация части 1/X
...
Объединение суммаризаций (если было более 1 части)
Суммаризация завершена: XXXX символов
```

## Технические детали для отладки

### Проверка количества токенов

При необходимости отладки, можно добавить логирование:

```python
# В методе summarize_chunk()
inputs = self.model_manager.qwen_tokenizer(
    prompt,
    return_tensors="pt",
    truncation=True,
    max_length=24000
).to(self.model_manager.qwen_model.device)

# Добавить логирование
input_length = len(inputs.input_ids[0])
self.logger.info(f"Input tokens: {input_length}")
self.logger.info(f"Will generate up to: {input_length + max_tokens} total tokens")
```

### Проверка сгенерированного текста

```python
# После генерации
generated_ids = outputs[0][len(inputs.input_ids[0]):].tolist()
self.logger.info(f"Generated tokens: {len(generated_ids)}")
self.logger.info(f"Expected max tokens: {max_tokens}")
```

## Проблемы, которые могут возникнуть

### Проблема 1: Все еще обрезано

Если проблема все еще присутствует:
1. Проверить, что изменения сохранены в файле
2. Пересобрать Docker образ: `docker-compose build --no-cache`
3. Перезапустить контейнер: `docker-compose down && docker-compose up -d`

### Проблема 2: CUDA out of memory

Если возникает ошибка памяти:
1. Уменьшить `max_length` при токенизации (обратно на 20000 или 18000)
2. Уменьшить `max_new_tokens` в `SUMMARY_MAX_NEW_TOKENS` конфиге
3. Убедиться, что GPU имеет достаточно памяти

### Проблема 3: Медленнее работает

Если обработка стала медленнее:
- Это ожидается, т.к. модель может генерировать больше токенов
- Проверить, что GPU не перегружена
